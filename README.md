# yardeni-intel

Dashboard personale con gli articoli Yardeni ricevuti via email, **grafici compresi**.
Pubblicata su Cloudflare Pages: https://yardeni-intel.pages.dev

- `apps-script/yardeni_v3.gs`: script Google Apps Script (Gmail → Drive → GitHub), da eseguire ogni ora
- `docs/GUIDA_SETUP_v3.md`: guida di installazione passo passo
- `index.html`, `articoli/`, `articoli.json`: generati dallo script, **da non modificare a mano**
- `apps-script/vecchi/`: script precedenti (v2.5 e publisher), tenuti come riferimento
