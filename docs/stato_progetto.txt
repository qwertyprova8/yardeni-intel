BUG RILEVATI E RISOLTI IN QUESTA SESSIONE
Bug 1 — Cloudflare Pages Direct Upload non funziona da Apps Script

Problema: API Pages Direct Upload richiede formato multipart con manifest+hash MD5 non documentato ufficialmente e non costruibile da Apps Script. Tentativi: 3 approcci diversi (boundary manuale, blob nativo, upload-config) — tutti falliti. Soluzione adottata: Apps Script → GitHub API (PUT base64, semplicissimo) → Cloudflare Pages rileva commit → deploy automatico. Zero manifest, zero multipart.

Bug 2 — Il sito si fermava alla data del 20 giugno pur avendo file più recenti

Problema: lo script usava f.getDateCreated() (data di creazione su Drive = data di sincronizzazione dal PC, non data dell'email). I file del 21-24 giugno erano stati sincronizzati in ritardo e risultavano "fuori finestra". Soluzione: lo script ora legge la data direttamente dal nome del file (formato YYYY-MM-DD - Titolo.txt) — robusta e indipendente dalla metadata Drive. Stato: fix applicato nello script v5, da testare al prossimo lancio manuale.

Bug 3 — Token GitHub condiviso in chat (sicurezza)

Problema: Andrea ha incollato in chat il token GitHub in chiaro. Azione: token revocato immediatamente, nuovo token creato e inserito solo nello script. Regola operativa: i token non si condividono mai in chat, solo nello script direttamente.
